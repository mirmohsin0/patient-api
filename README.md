# 🚀 Patient API (FastAPI)

A RESTful API built with FastAPI to manage patient records using JSON storage.

---

## 🔥 Features
- Get all patients
- Add a new patient
- Update patient details
- Delete patient records

---

## 🛠 Tech Stack
- Python
- FastAPI
- Uvicorn
